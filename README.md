# C++ Coursework Portfolio
## What is this?
This repo is designed purely to stage and host my portfolio of C++ projects I completed during my Spring 2024 coursework. It is not a full reflection of my capabilities, just a view into real C++ projects I created. I recommend downloading the PDF as it was developed in LaTeX and some interactive features, such as the table of contents, will be missing if not.

## Generative AI involvement 
This coursework was completed in Spring 2024 when UML's stance on generative AI in the Computer Science department was firmly against involvement in this class (Computing 4). I will state and maintain honestly that **I did not use any generative AI** (e.g. ChatGPT, Claude Code, Microsoft Copilot, or even IntelliSense autocomplete in VSCode, among others) to write these projects. I used C++ documentation on the web, primarily https://cppreference.com/, https://cplusplus.com/, and https://www.geeksforgeeks.org/ to develop my understanding, along with consistent communication with my professor through Discord and office hours.

With this in mind, during later coursework generative AI began being encouraged as a tool for debugging and code refactoring, and I want it to also be known I understand the important role that generative AI is playing in the modern workflow. For that reason, I also have been developing fluency in using generative AI to develop **beyond this portfolio**, though it has never been a substitution for my own work!
